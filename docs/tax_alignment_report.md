## ingest 規範化規則

`scripts/ingest_segis.py` 內 `NORMALIZATION_STATS` 統計處理量：

| 規則 | 累計處理數 | 處理對象 |
|---|---|---|
| `drop_villagename_aggregate` | 5,251 | VILLAGE 為「其他/合計/小計/總計」（含全形空白變體「其　他」）的彙整列 |
| `fix_town_leading_zero` | 118 | 7 位 TOWN_ID 補前導 0（連江縣 09007XXX 被 csv 寫成 9007XXX）|
| `fix_town_rebuild` | 48 | TOWN_ID 開頭與 COUNTY_ID 不符，用 COUNTY_ID + 末 3 位重組（110 雲林斗南鎮 TOWN_ID=100009020 → 10009020）|
| `rebuild_from_town_id` | 26 | V_ID 開頭非 8 位數，用同列 TOWN_ID 重組（含 `=054` typo 與 `100009020-XXX` typo）|
| `drop_999_aggregate` | 250 | V_ID 末三碼 `-999` 的彙整列 |
| `fix_equal_sign` | 0 | `=` → `-`（在 VILLAGE 過濾後沒剩任何此類列）|

注意：累計數會跨所有主題（11 主題 × 14 年），且 `drop_villagename_aggregate`
跨主題重複計算（因為同一個村里同一年的彙整列在每個主題 csv 都有一筆）。

### 5. 已修正的 typo 詳情

#### 5.1 110 (2021) V_ID typo
財政部 110 csv 內 25 列雲林斗南鎮資料：
```
原始 raw 字串:  TAG=X, TOWN_ID=100009020, V_ID=100009020-003, VILLAGE=南昌里
ingest 規範化後: TOWN_ID=10009020, V_ID=10009020-003 ✓
```
TOWN_ID 開頭 `100` 與 COUNTY_ID `10009` 不符 → 用 `COUNTY_ID + 末 3 位` 重組為 `10009020`，再用該 TOWN_ID 重組 V_ID。

#### 5.2 112 (2023) `=054` typo
```
原始: V_ID=10018010=054, VILLAGE=其他/合計
規範化: VILLAGE 含「其他/合計」直接過濾 (drop_villagename_aggregate)
```
