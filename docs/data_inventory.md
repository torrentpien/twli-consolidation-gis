- 來源平台：社會經濟資料服務平台（內政部）

## 3. CSV 主題類別

各時點底下的 csv 檔均遵循命名模式：
`<民國年><月>行政區XXX_村里.csv`

確認共有 10 種主題（早年缺少教育程度，後詳）：

| 代碼 | 主題                                  | schema 重點                          |
|------|---------------------------------------|--------------------------------------|
| P    | 行政區人口統計                         | H_CNT, P_CNT, M_CNT, F_CNT           |
| PI   | 行政區人口指標                         | 多項指標欄位                          |
| 3A   | 行政區三段年齡組性別人口統計           | 0-14 / 15-64 / 65+ × 性別            |
| 5A   | 行政區五歲年齡組性別人口統計           | 5 歲組 × 性別                         |
| 10A  | 行政區十歲年齡組性別人口統計           | 10 歲組 × 性別                        |
| CY   | 行政區分齡兒童及少年性別人口統計       | 兒少細分齡                            |
| IP   | 行政區原住民人口統計                   | 同 P 結構                             |
| IPI  | 行政區原住民人口指標                   | 同 PI 結構                            |
| IP10 | 行政區原住民十歲年齡組性別人口統計     | 同 10A 結構                           |
| EDU  | 行政區 15 歲以上人口教育程度統計        | 各教育程度 × 性別                     |

完整欄位以實際讀取 csv 第 1–2 列 header 為準。


## 6. 取得權威檔案清單

由於 MCP 工具一次回傳大量 metadata 不利於完整盤點，本 repo 附上獨立腳本：

```bash
# 1. 建立 Google Cloud 服務帳號，啟用 Drive API，下載 JSON 金鑰
# 2. 把該 service account email 加入分享資料夾（檢視者即可）
# 3. 跑：
pip install google-api-python-client google-auth
python scripts/list_drive_inventory.py \
    --service-account /path/to/service_account.json \
    --output docs/data_inventory.json
```

輸出 `docs/data_inventory.json` 後，後續分析直接讀此 JSON 即可，不再需重複呼叫 Drive API。

## 7. 後續延伸應用提示

1. **ingest 階段**：用 `download_file_content` 把每個權威 csv 拉成 base64 後存成 `data_population/<snapshot>/<topic>.csv`（已加入 `.gitignore`，避免 repo 變大）。
2. **整併階段**：對每個 12 月快照，呼叫 `twli_consolidate.build_ref(events, year_range=(2010, 2024), data_year=<西元>)`，再用 `li_sum` / `li_equ` 重算欄位。
3. **panel 串接**：將 15 個 12 月快照拼成 long-format panel；SAU 已由 lineage 自動串接（民國 100 五都升格、民國 104 桃園升格的 V_ID 重編皆已記錄）。
4. **編碼陷阱**：人口 csv 偶有亂碼字（例 `公?里`），請用 V_ID 比對 SHP 取回正確村名再使用，不要信任 csv 內的中文名。
